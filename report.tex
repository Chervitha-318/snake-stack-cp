\section{Introduction}
 The project is to build a browser-based Snake game with a full three-layer architecture: 
 

\begin{itemize}
    \item JavaScript frontend that the player interacts with, a Python (Flask) backend that receives and stores game results, and a Bash administration script for inspecting and managing stored data from the terminal
    \item Each layer has a single, well-defined responsibility and must not reach into the concerns of another layer
    \item JavaScript does not know how scores are saved. The Bash script does not know how the game works. Flask sits in between and connects them
\end{itemize}




\section{Installation and Running Instructions}

\begin{itemize}
    \item Clone the repository
    \item Make sure  Python 3.10 and Flask (v2.x) is installed 
    \item Run backend:
\begin{verbatim}
python3 app.py
\end{verbatim}
    \item The game is accessible at http://127.0.0.1:5000 once the server is running

\end{itemize}

    \item \texttt{/get\_profile} (GET): Returns user data
\end{itemize}

\section{Data Storage Format}

Each game is stored as:

\begin{verbatim}
[YYYY-MM-DD HH:MM:SS] username | score | cause | duration
\end{verbatim}

\textbf{Reasons:}
\begin{itemize}
    \item Human readable
    \item Easy parsing with Bash tools
    \item Fixed delimiter simplifies extraction
\end{itemize}

\section{Features Implemented}

\begin{itemize}
    \item \textbf{Username Input Box:}
    At the start, a username box appears.If left empty gives a warning saying please enter username!.
    
    \item \textbf{Home Page:}
    After entering username, the homepage appears containing three options:
    \begin{itemize}
        \item \textbf{Rules:} Displays rules for the game in a seperate box.
        \item \textbf{Start:} Launches the game and initialize the canvas.
        \item \textbf{Profile:} This gets the data from backend and displays username,highscore,total games played,last score and last cause.
        This feature demonstrates frontend-backend interaction using API calls.
    \end{itemize}

    \item \textbf{Game over Box:}
    At the end of each game, a box appears:
    \begin{itemize}
        \item Final score
        \item Time survived
        \item Cause of death
        \item Timestamp
        \item Overall High score of the user
        \item Current session high score of the user
    \end{itemize}
\end{itemize}
